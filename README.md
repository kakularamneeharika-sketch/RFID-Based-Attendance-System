RFID-Based-Attendance-System
The RFID Based Attendance System is an embedded systems project used to record student attendance automatically. It uses an RFID card and RFID reader to identify students. When a student scans their card, the system reads the card ID and displays the attendance status.

INTERN ID:CIS207

RFID Based Attendance System
Introduction
This project is designed to record student attendance using RFID technology and Arduino UNO.

Components Required
Arduino UNO
RC522 RFID Reader
RFID Cards
Buzzer
Jumper Wires
Breadboard
Working Principle
The RFID reader scans the card and reads its unique ID. Arduino checks the ID with the registered card details. If the card is valid, attendance is marked and a buzzer gives an alert.

Applications
Schools and Colleges
Offices
Employee Attendance
Student Attendance Management
Technologies Used
Embedded Systems
Arduino IDE
C++ Programming
RFID Technology
Conclusion
This project provides a simple way to identify users and record attendance using RFID technology.
